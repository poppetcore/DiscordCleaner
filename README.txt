Discord Cleaner v1.4.10

설치
1. ZIP을 압축 해제합니다.
2. Chrome의 chrome://extensions에서 개발자 모드를 켭니다.
3. '압축해제된 확장 프로그램 로드'에서 manifest.json이 있는 discord-cleaner 폴더를 선택합니다.
4. Discord 웹사이트에 로그인한 상태에서 확장 프로그램 팝업을 엽니다.
별도 빌드, npm install 또는 개발 서버는 필요하지 않습니다.

사용
대상과 검색 조건을 확인한 뒤 검색/삭제를 시작합니다. DM 일괄 삭제는 선택한 대화의 본인 메시지만 처리합니다.
삭제 전 확인, 작업 진행 상황, 작업 중단 및 민감 정보 가리기는 기존 기능 그대로입니다.
