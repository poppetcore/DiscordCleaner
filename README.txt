[ 프로젝트 소개 ]
-------------------------------------------------------------------------------

Discord Cleaner 1.3.1
제작자: poppetcore(포코)

Chrome 계열 브라우저용 Manifest V3 확장 프로그램입니다.
로그인된 Discord 웹 세션으로 서버·채널·DM 메시지를 검색하고 정리합니다.
Victornpb와 기여자들의 Undiscord를 바탕으로 제작한 비공식 독립형 이식판이며,
Discord 또는 원작자의 공식 제품이 아닙니다.

-------------------------------------------------------------------------------
[ 주요 기능 ]
-------------------------------------------------------------------------------

- 현재 Discord 탭과 서버·채널·일반 DM·그룹 DM 자동 인식
- 서버명, 채널명과 닉네임·사용자명 표시, DM 작성자를 대화 참여자로 제한
- 현재 채널 또는 현재 서버 전체 채널 검색, 작성자 선택
- 검색어, 링크·첨부파일·고정 메시지·NSFW 검색 조건
- 날짜·메시지 ID 범위, 정규식, 검색·삭제 간격 설정
- 삭제 전 확인창, 작업 중단, 중복 실행 방지
- 제한적인 선행 검색과 독립 삭제 대기열을 통한 검색·삭제 병행
- 전체 검색 기준 진행률, 검색·삭제 집계, 제한된 작업 로그
- 메시지 삭제 / 검색 필터 / 작업 진행 상황 탭과 민감 정보 가리기
- Freesentation 서체 400/500/600/700 로컬 로딩

-------------------------------------------------------------------------------
[ 설치 방법 ]
-------------------------------------------------------------------------------

1. ZIP을 고정된 위치에 압축 해제합니다.
2. chrome://extensions 또는 edge://extensions를 엽니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
4. discord-cleaner/ 안의 manifest.json이 있는 폴더를 선택합니다.
5. 로그인된 Discord 탭을 새로고침합니다.
6. 도구 모음의 Discord Cleaner 아이콘을 눌러 사용합니다.

Chrome 111 이상을 대상으로 합니다. 별도 서버나 실행용 Node.js는 필요 없습니다.
브라우저 및 Discord 버전에 따른 실제 호환성은 사용 환경에서 확인해야 합니다.

-------------------------------------------------------------------------------
[ 업데이트 방법 ]
-------------------------------------------------------------------------------

1. 진행 중인 작업을 중단하고 기존 설치 폴더를 별도로 복사해 두세요.
2. 기존 폴더를 새 배포본의 내용으로 교체해 이전 이름의 파일이 남지 않게 하세요.
3. 확장 프로그램 관리 화면에서 다시 로드합니다.
4. 열려 있는 Discord 페이지도 새로고침합니다.

버전은 1.3.1로 유지됩니다. 이전 실행 코드가 남은 Discord 탭은 새 검색·승인을
차단하므로 확장 프로그램과 Discord 페이지를 모두 다시 로드해야 합니다.
페이지 종료·새로고침 후 작업을 자동 재개하거나 이전 로그를 복구하지 않습니다.

-------------------------------------------------------------------------------
[ Discord 탭 및 삭제 대상 선택 ]
-------------------------------------------------------------------------------

현재 창의 활성 탭이 Discord 채널 또는 DM이면 해당 탭을 사용합니다.
다른 사이트가 활성 상태라면 Discord 채널 탭이 하나일 때만 사용합니다.
여러 Discord 탭 중 대상이 모호하면 실행하지 않습니다.
원하는 Discord 채널 또는 DM 탭을 활성화한 뒤 확장 프로그램을 여세요.

서버에서는 현재 채널 또는 '현재 서버 전체에서 검색'을 선택합니다.
DM은 현재 대화 범위로 검색하며 작성자는 현재 대화 참여자 중 선택합니다.
작성자를 지정하지 않으면 '전체 작성자'입니다. 본인 메시지만을 뜻하지 않습니다.

일반 DM은 'DM' 제목 아래에 '닉네임(사용자명)'을 표시합니다.
그룹 DM은 그룹 이름이 있으면 그 이름, 없으면 '그룹 DM'으로 표시합니다.
숫자 서버·채널·작성자 ID는 내부 매핑에 사용합니다.
이름을 확인하지 못하면 추측하지 않고 '정보 확인 불가'로 표시합니다.

-------------------------------------------------------------------------------
[ 메시지 삭제 방법 ]
-------------------------------------------------------------------------------

1. 메시지 삭제 탭에서 대상 서버·채널·DM과 작성자를 확인합니다.
2. 검색 필터 탭에서 필요한 조건을 설정합니다.
3. '검색 및 삭제'를 누르면 먼저 검색하고 삭제 확인창을 표시합니다.
4. 대상과 작성자, 검색 조건 및 복구 불가 경고를 확인합니다.
5. '삭제 시작'을 눌러야 실제 삭제가 시작됩니다.

실제 삭제 가능 여부는 현재 Discord 계정과 채널의 권한에 따릅니다.

-------------------------------------------------------------------------------
[ 검색 필터 설정 ]
-------------------------------------------------------------------------------

- 검색어: 메시지 내용 검색 조건입니다.
- 링크 / 첨부파일: 해당 항목이 포함된 메시지로 검색을 제한합니다.
- 고정 메시지 포함: 기본적으로 제외되는 고정 메시지를 포함합니다.
- NSFW 검색: NSFW 채널을 검색 조건에 포함할지 선택합니다.
- 날짜 / 메시지 ID: 시작·종료 경계를 지정합니다. 날짜는 현지 시간입니다.
  같은 방향의 ID와 날짜를 모두 입력하면 메시지 ID가 우선합니다.
  메시지 링크 입력창에는 Discord 메시지 링크 또는 숫자 ID를 입력할 수 있습니다.
- 정규식: 검색 응답에 추가로 적용하는 로컬 메시지 필터입니다.
- 검색 간격: 기본 30000ms입니다.
- 삭제 간격: 기본 1000ms입니다.

Discord가 요구한 제한 대기 시간이 우선 적용됩니다.
상세 필터 펼치기/접기로 조건을 확인할 수 있습니다.

-------------------------------------------------------------------------------
[ 삭제 확인창 사용 방법 ]
-------------------------------------------------------------------------------

확인창은 서버·채널 또는 DM 대상, 작성자, 검색 결과(추정)를 요약합니다.
검색 결과는 최종 삭제 예정 건수가 아니며 전체 건수가 없으면 '확인 중'입니다.
'검색 조건 상세보기'는 처음에 접혀 있고, 펼치면 입력한 조건을 확인할 수 있습니다.
헤더와 복구 불가 경고·버튼이 있는 푸터는 고정되며 콘텐츠만 내부 스크롤합니다.

'취소', 닫기 또는 Escape는 승인 대기 작업을 중단하고 메시지 삭제 탭으로
돌아갑니다. 입력 조건은 유지됩니다. '삭제 시작'은 작업 진행 상황 탭으로 이동합니다.
확인창 안에서 Tab/Shift+Tab으로 이동하며 중복 승인 요청을 방지합니다.

-------------------------------------------------------------------------------
[ 작업 진행 상황 및 중단 ]
-------------------------------------------------------------------------------

작업 진행 상황 탭에서 검색 건수, 삭제 성공·실패와 로그를 확인합니다.
다른 기능 탭으로 이동하거나 팝업만 닫아도 Discord 탭의 작업은 계속됩니다.
팝업을 다시 열면 상태를 조회합니다. Discord 페이지를 닫거나 새로고침하면
해당 페이지의 작업은 종료됩니다. 채널·DM 이동이 감지되어도 이전 작업을 중단합니다.

'작업 중단'은 대기와 새 요청을 중단합니다. 이미 처리된 삭제는 되돌리지 못합니다.
응답을 받지 못한 요청은 서버에서 처리되었을 수도 있으므로 마지막 집계가
서버의 최종 결과를 완전히 나타내지는 않습니다.
'민감 정보 가리기'는 화면 표시를 가리는 기능이며 데이터를 삭제하거나 암호화하지 않습니다.

-------------------------------------------------------------------------------
[ 검색 및 삭제 결과 해석 ]
-------------------------------------------------------------------------------

진행 막대는 전체 검색 대상의 처리 비율이며 삭제 성공률이 아닙니다.
검증 전에는 최대 99%이며 최종 실패가 있으면 100%여도 '일부 미처리'입니다.
삭제 성공·최종 실패·확정 제외를 구분하고 고유 메시지 ID로 중복 집계를 막습니다.

검색 GET의 네트워크 오류와 서버 오류는 최대 총 4회 요청 안에서 재시도합니다.
HTTP 429와 검색 GET의 202는 서버 retry_after와 Retry-After 중 긴 값을 준수합니다.
검색과 삭제는 병행하되 검색끼리·삭제끼리는 직렬 실행합니다.
전체 제한(global)은 두 경로가 공유하고, 경로 제한과 응답의 reset-after도 준수합니다.
401·403은 재시도하지 않습니다.

삭제 DELETE의 네트워크 오류는 서버에서 이미 처리했을 가능성이 있으므로,
같은 요청을 자동 재전송하지 않고 오류로 종료합니다.
DELETE가 202를 반환하면 요구된 대기 후 결과 미확정 오류로 중단합니다.
삭제 429는 서버가 거절한 요청으로 보고 제한된 재시도를 수행합니다.
성공 응답을 확인하지 못한 메시지를 성공 처리하지 않습니다.
확인된 실패 메시지는 같은 작업의 재검색에서 자동 재삭제하지 않습니다.

'미처리'는 실제 확인한 삭제 대상 중 아직 요청 결과가 기록되지 않은 건수입니다.
'실패'는 최종 HTTP 실패 응답이 확인된 건수입니다. 네트워크 응답 미확정은
실패로 단정하지 않고 미처리로 보존하며, 서버에서 이미 삭제되었을 수도 있습니다.
추정치와 관측치의 차이만으로 미처리 건수를 만들지 않습니다.
미처리 0건이어도 검증 한도나 검색 불안정으로 일부 미처리 상태가 될 수 있습니다.

'완료'는 동일 조건의 연속 재검색에서 더 이상 삭제 대상을 확인하지 못했다는 뜻입니다.
Discord 검색 인덱스의 누락·지연, 새 메시지 유입 등으로 모든 과거 메시지의 삭제를
절대적으로 보증하지 않습니다. API 오류는 오류, 사용자 중단은 중단됨으로 표시합니다.

-------------------------------------------------------------------------------
[ 데이터 저장 및 개인정보 보호 ]
-------------------------------------------------------------------------------

검색·삭제 요청은 Discord로 전송됩니다.
확장 프로그램 전용 외부 서버로 토큰이나 메시지를 업로드하지 않습니다.
인증 정보는 기존 Discord 세션의 저장값 또는 내부 인증 getter에서 얻어
실행 중 메모리에서 사용하며, 확장 프로그램의 별도 영구 저장소에 새로 기록하지 않습니다.
원래 Discord 세션의 저장값 자체를 삭제하거나 변경하는 기능은 아닙니다.

서버·사용자 이름은 이미 로드된 Discord 캐시와 렌더링 데이터에서 확인합니다.
이름 조회를 위해 별도 프로필 API 요청을 추가하지 않습니다.
탭 내부에는 작업 조건·집계와 최대 500개의 제한된 로그, 승인 대기 중의 제한된
미리보기가 유지됩니다. 메시지 본문 전체를 작업 이력으로 영구 저장하지 않습니다.
현재 페이지와 선행 페이지를 처리하며 ID별 처리 원장에는 상태·사유를 보관합니다.

chrome.storage.session에는 탭별 명령 검증 값, 작업 ID·상태·집계·진행률·결과와
중단 정보 등 최소 상태 사본을 저장합니다. 인증 토큰, 메시지 본문, 미리보기와
메시지 로그는 이 상태 저장소에 기록하지 않습니다.
탭 종료 시 최종 결과는 확인할 수 없고 마지막 조회 상태만 남을 수 있습니다.

-------------------------------------------------------------------------------
[ 사용 시 주의사항 ]
-------------------------------------------------------------------------------

이 도구는 Discord의 비공식 내부 구조와 API를 이용합니다.
사용자 계정 자동화는 Discord 정책 위반 및 계정 이용 제한으로 이어질 수 있습니다.
요청 간격과 서버 대기 시간을 반영해도 이러한 위험이 없어지는 것은 아닙니다.

- 삭제한 메시지는 복구할 수 없습니다. 대상과 작성자를 먼저 확인하세요.
- '전체 작성자'는 본인 메시지만을 뜻하지 않습니다. 권한과 범위를 확인하세요.
- 요청 제한이나 인증 오류가 나면 반복 실행하지 말고 상태를 확인하세요.
- Discord 내부 구조 변경으로 이름 조회·검색·삭제가 실패할 수 있습니다.
- 중단 시 이미 완료된 삭제는 유지되고 응답 미확정 항목은 미처리로 남을 수 있습니다.
- 완료는 연속 재검색에서 삭제 대상을 더 찾지 못했다는 뜻입니다.
  검색 인덱스 누락·지연 및 새 메시지 유입 때문에 모든 과거 메시지 삭제를 보증하지 않습니다.
- 팝업 종료는 작업을 끝내지 않지만 Discord 페이지 종료·새로고침은 작업을 종료합니다.

1.3.1 — 선행 검색 및 전체 진행률 개선
- 검색 간격 대기, Discord 제한 대기, 네트워크 재시도, 잔여 확인을 구분합니다.
- 대기 시간은 실제 예약 시각을 기준으로 표시하며, 중단 시 즉시 해제합니다.
- 검색 추정치와 실제 확인한 고유 메시지·삭제 대상·성공·실패·제외·미처리를 구분합니다.
- 메시지 ID별 처리 이력으로 중복 삭제와 중복 집계를 방지합니다.
- 고정·시스템·작성자·채널·정규식 등의 제외 사유는 한 메시지당 한 가지로 집계합니다.
- timestamp 내림차순과 max_id 경계로 검색합니다. 삭제 중에도 다음 한 페이지를
  미리 가져오며, 현재 삭제 대기열이 끝날 때까지 추가 페이지는 요청하지 않습니다.
- 검색 간격은 직전 실제 검색 요청 시작 시각을 기준으로 적용합니다.
- 종료 전 동일 조건으로 전체 검색을 다시 순회합니다.
  최대 4회 재검증 중 연속 2회 안정적인 순회를 마쳐야 완료로 판정합니다.
  검증 사이에는 사용자 검색 간격을 지키며, 최소 1초 이상 대기합니다.
- 한 순회는 최대 1000페이지, 한 작업은 최대 200000개 고유 메시지를 확인합니다.
  한도·반복 페이지·불안정한 검색 결과로 확인을 끝내지 못하면 일부 미처리입니다.
- 확인된 삭제 실패가 남아도 완료로 처리하지 않습니다.
- 검색 추정치와 성공 건수의 차이를 제외·미처리로 임의 보정하지 않습니다.
- 진행 막대는 최초 전체 검색의 total_results를 기준으로 계산합니다.
  분자는 고유 메시지의 삭제 성공·최종 실패·확정 제외 건수입니다.
  검색·대기·진행 중·재시도·미확정 응답은 분자에 포함하지 않습니다.
  관측한 고유 메시지가 초기 전체 건수를 넘으면 분모를 상향 보정합니다.
  전체 건수를 모르면 불확정 막대를 표시합니다. 검증 전에는 최대 99%입니다.
  연속 잔여 확인 후 모든 관측 항목의 처리가 확정되면 전체 분모를 정리하여
  100%를 표시합니다. 최종 실패가 있으면 100%여도 상태는 일부 미처리입니다.
  결과 0건도 검증 완료 후에는 100%이며, 삭제 성공률을 뜻하지 않습니다.
  중단·오류 후에는 마지막으로 확정된 진행 상태를 유지합니다.
- 기존 실행 코드가 남아 있는 Discord 탭에서는 새 검색·승인을 차단합니다.
  업데이트 전 작업을 중단하고, 확장 프로그램과 Discord 페이지를 다시 로드하세요.
